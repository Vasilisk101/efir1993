# Руководство читателя

## Начать с обложки

Сайт открывается выпуском «Куплю, продам», P510. На обложке нажмите на заголовок или фрагмент газетного объявления, чтобы открыть материал. Каждая запись имеет собственный номер. Например, на [P513](https://efir-1993.gubarevf.chatgpt.site/#513) можно прочитать, какую машину предлагал автор объявления и что хотел получить взамен.

Для перехода по известному номеру наберите три цифры подряд вне поля ввода. Третья цифра открывает страницу. На телефоне нажмите на обозначение текущей страницы в шапке, например **P510**, и введите номер в поле «Перейти к странице». Набирайте только цифры. У незавершённого номера есть пауза в 2,5 секунды, после которой ввод сбрасывается.

Чтобы поделиться записью, передайте короткую ссылку с номером, например [P511](https://efir-1993.gubarevf.chatgpt.site/#511). Адрес из строки браузера тоже работает. В нём могут быть дополнительные параметры, которые сохраняют поисковый запрос, фильтр или раздел, откуда вы пришли.

## Найти материал по содержанию

Нажмите «Поиск» или клавишу `/`. Откроется [указатель P100](https://efir-1993.gubarevf.chatgpt.site/#100). Начните вводить слово, год, название издания или номер записи. Результаты обновляются при наборе. Например, по запросу «пиломатериалы» можно найти объявление об обмене автомобиля. Несколько слов сужают выбор. Буквы «е» и «ё» при поиске равнозначны.

В списке рядом со строкой поиска выберите вид материала. Этот фильтр относится к самой записи. Для поиска непосредственно снимков, видеозаписей и фрагментов документов откройте [медиатеку P700](https://efir-1993.gubarevf.chatgpt.site/#700). Там можно выбрать фото, видео или сканы и перейти от изображения к записи, где указаны его происхождение и дата.

## Рассмотреть источник

В карточке сначала прочитайте подпись к изображению. Она помогает отличить газетный фрагмент, архивный снимок или современную схему. У материалов с просмотром скана нажмите на изображение либо на кнопку увеличения. Кнопки `+` и `−` в окне меняют масштаб от 100 до 400 процентов. При увеличении прокручивайте изображение внутри окна. Для выхода нажмите «Закрыть» или `Esc`.

У отдельных записей есть свои инструменты. На [P201](https://efir-1993.gubarevf.chatgpt.site/#201) кнопка «Рассмотреть часы» показывает деталь фотографии Дома Советов. На [P301](https://efir-1993.gubarevf.chatgpt.site/#301) можно перейти от строки бюллетеня к её месту на скане. Кнопка «Сравнить» у записей с парным источником открывает два материала с пояснениями. Из окна сравнения можно перейти во вторую запись.

В [кинохронике P204](https://efir-1993.gubarevf.chatgpt.site/#204) доступен официальный видеопоток. Внешние источники открываются в новой вкладке. Если правообладатель или библиотека предоставляют материал только на своей площадке, в записи есть ссылка и описание того, что там доступно. Для просмотра внешних страниц и видео нужно соединение с интернетом.

## Собрать свою кассету

Откройте запись и нажмите «+ На кассету». Закладка появится на [P900](https://efir-1993.gubarevf.chatgpt.site/#900). Чтобы убрать её, откройте ту же запись и нажмите «✓ На кассете». Если открыть запись из кассеты, соседние материалы для перелистывания берутся из вашей подборки.

Закладки хранятся в `localStorage` текущего браузера для этого адреса сайта. На другом устройстве, в другом профиле или по адресу локальной копии будет своя кассета. Очистка данных сайта удаляет сохранённый список. Если браузер блокирует запись в хранилище, кассета доступна только до закрытия или перезагрузки вкладки.

## Клавиатура

| Клавиши | Где и что происходит |
| --- | --- |
| `0`–`9` | Вне поля ввода наберите три цифры для перехода. Например, `4`, `1`, `0` открывают «Свободный вечер». |
| `/` | Вне поля ввода открывает поиск по архиву и переводит курсор в строку запроса. |
| `↓` | Из строки поиска переводит фокус в список найденных записей. |
| `↑` / `↓` | В списке указателя или кассеты выбирают предыдущую или следующую запись. |
| `Home` / `End` | В списке переходят к первой или последней записи текущей выборки. |
| `Enter` | В строке поиска открывает выбранную запись. На ссылке или кнопке выполняет её действие. |
| `Tab` / `Shift+Tab` | Перемещают фокус между ссылками, полями и кнопками вперёд или назад. |
| `Esc` | Закрывает скан, сравнение или меню номера. В поиске очищает запрос, при наборе номера сбрасывает цифры. Из открытого материала возвращает назад. |

Для перехода к соседнему материалу в карточке используйте кнопки с названиями записей. Они учитывают раздел или выборку, из которой вы пришли. В шапке под номером страницы также доступны два независимых переключателя оформления — «Следы времени» и «Растр экрана». Их можно отключить, если фактура мешает читать мелкий текст.
