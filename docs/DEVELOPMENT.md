# Как устроен «Эфир»

Сайт работает в браузере без серверной базы. В `dist/` лежат файлы, которые получает читатель. Порядок подключения скриптов задан в [index.html](../dist/index.html). Для правки вёрстки или записей этап сборки не требуется.

| Файл | Ответственность |
| --- | --- |
| [archive.js](../dist/archive.js) | Каталог в `window.EFIR_RECORDS`. У каждого источника свой постоянный трёхзначный номер |
| [app.js](../dist/app.js) | Маршруты, поиск, кассета, читалка, сканы, сравнение и обложки P200/P410 |
| [daily.js](../dist/daily.js) | Заголовки, подлинные газетные фрагменты и ссылки обложки P510 |
| [media.js](../dist/media.js) | Материалы к записи, видеоплееры, фильтры и строки медиатеки |
| [screen.css](../dist/screen.css), [daily.css](../dist/daily.css), [library.css](../dist/library.css) | Оболочка телетекста, новый выпуск, читательские инструменты и медиатека |
| [assets](../dist/assets/) | Шрифты, фотографии, вырезки, логотип и фактуры для автономного просмотра |

## Маршруты и сохранение состояния

`parseRoute()` читает номер после решётки. Для номера раздела `baseState()` выбирает обложку или указатель. У материала физически одна запись, независимо от того, пришёл читатель из нового выпуска, поиска или кассеты. `encode()` сохраняет номер исходного раздела в `from`, выбранную запись в `sel`, параметры поиска — в `q` и `type`, раздел медиатеки — в `media`. Например, `#204?from=700&media=video` открывает кинохронику со ссылкой возврата в видеораздел.

`setRoute()` изменяет историю браузера. `render()` выбирает экран, а `readCode()` открывает материал и переводит фокус на его заголовок. `matching()` определяет выдачу поиска и порядок перелистывания. `renderBytFront()` размещает обложку третьего выпуска в подготовленном разделе. Новая обложка может использовать существующий обработчик ссылок через `href="#NNN"` и `data-issue-code="NNN"`.

## Архивная запись

| Поля | Содержание |
| --- | --- |
| `id`, `code` | Внутренний идентификатор и постоянная страница |
| `title`, `shortTitle`, `date`, `type`, `typeLabel` | Заголовки, точность датировки и вид материала в поиске |
| `edition.lead`, `edition.paragraphs` | Вводный текст и абзацы читалки |
| `source`, `credit`, `originalUrl` | Выходные данные, авторство и постоянная ссылка на источник |
| `imageData`, `mediaAlt`, `edition.caption` | Путь к основному снимку или скану, описание для чтения с экрана, подпись |
| `edition.facts`, `factsTitle` | Строки таблицы в форме `{label, value}` и название показателя |
| `supplement.media` | Встроенный материал с `file`, `kind`, `alt`, `caption`, `url` и при необходимости `credit` |
| `supplement.links` | Внешний источник с `kind`, `url`, `label` и пояснением `note` |

`recordAttachments()` объединяет основную иллюстрацию и дополнительные материалы. `mergeAttachments()` сопоставляет дубли по виду и адресу, сохраняя подписи и локальные файлы. `renderArchiveExtra()` выводит источники внутри материала, а `renderMediaShelf()` даёт другой путь к тем же объектам через вид источника. Видео с внешнего сервера загружается при обращении к плееру.

Для новой записи подберите свободный номер, добавьте его в месяц указателя и в список нужного выпуска в `app.js`. Для P510 также добавьте ссылку на обложку в `daily.js`. Положите локальную копию в `assets/` и проверьте лицензию, подпись, единицы цены и дату. В [каталоге источников](SOURCES.md) укажите конкретную полосу, таблицу или кадр.

## Проверка и распространение

Из корня проекта выполните:

```sh
python tools/check.py
python -m http.server 8000 --directory dist
```

Проверьте открытие прямой ссылки, возврат из карточки к результатам поиска, увеличение скана и сохранение в кассету после перезагрузки. Отдельно откройте сайт при ширине 320 и 820 пикселей. Убедитесь, что каждая видимая ссылка ведёт к заявленному объекту.

Команда `python tools/standalone.py efir.html` создаёт переносной HTML со встроенными шрифтами, стилями и локальными иллюстрациями. Результат следует сохранять вне `dist/`. Оригиналы в сторонних архивах и видеопотоки требуют доступа к сети.

В Sites этот проект развёртывается как статический сайт из `dist/`. Идентификатор действующего проекта и каталог публикации находятся в `.openai/hosting.json`. Доступ к опубликованной версии задаётся в Sites. Папка `history/` хранит самостоятельные ранние прототипы для чтения истории дизайна.
